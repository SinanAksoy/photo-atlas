Samsung photo location tips

A street address shown in Samsung Gallery does not guarantee that GPS coordinates are inside the file your browser receives. Try selecting the original file from My Files → Internal storage → DCIM → Camera. Shared, downloaded or edited copies may not retain GPS. If you still see “No embedded GPS,” use Tap map to pin or enter coordinates.

Backup & transfer

Photos are stored in this browser, not on GitHub. Use a backup to move them to another device.
Map provider & Google Maps

OpenStreetMap-based view: no API key or billing needed. Map tiles are provided by CARTO / OpenStreetMap. You can switch tiles if one provider isn't loading.

Google Maps requires your own Maps JavaScript API key and a Google Cloud project with billing enabled. This site cannot supply a Google API key. Protect a browser key using HTTP-referrer restrictions for https://sinanaksoy.github.io/* and limit it to Maps JavaScript API. Setup instructions.

Privacy: uploads stay in your browser and are stored locally in IndexedDB. Map requests (and manual place searches) contact third-party map services. Web storage can be cleared by the browser. This site needs an internet connection for maps and enhanced metadata reading.
